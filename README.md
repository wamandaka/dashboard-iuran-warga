# Jakmen – Dashboard Pembayaran Iuran Warga

Jakmen adalah aplikasi dashboard berbasis web yang digunakan untuk mengelola dan memantau pembayaran iuran warga secara digital. Aplikasi ini ditujukan untuk membantu pengurus lingkungan dalam mencatat pembayaran, memantau status iuran, serta menyajikan data secara rapi dan mudah dipahami.
