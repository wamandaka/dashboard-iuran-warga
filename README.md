# Jakmen – Dashboard Pembayaran Iuran Warga

Jakmen adalah aplikasi dashboard berbasis web yang digunakan untuk mengelola dan memantau pembayaran iuran warga secara digital. Aplikasi ini ditujukan untuk membantu pengurus lingkungan dalam mencatat pembayaran, memantau status iuran, serta menyajikan data secara rapi dan mudah dipahami.

## Tujuan Aplikasi

- Memudahkan pengurus dalam mengelola data pembayaran iuran warga
- Menyediakan tampilan data yang jelas dan terstruktur
- Mengurangi kesalahan pencatatan manual
- Mempercepat proses monitoring dan pelaporan

## Fitur Utama

- Dashboard ringkasan pembayaran
- Manajemen data warga
- Pencatatan dan status pembayaran iuran
- Tampilan tabel data dengan informasi pembayaran
- (Opsional) Filter dan pencarian data warga
- (Opsional) Role user (admin / pengurus)
